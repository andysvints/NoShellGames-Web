What it checks

What NoShellGames checks

NoShellGames performs static analysis of PowerShell scripts and highlights suspicious patterns that may deserve manual review.

Base64 encoded content Recursive decoding Invoke-Expression usage ScriptBlock creation Obfuscated variable names Character casting Add-Type usage Web requests WMI usage
What you get

What you get

The analyzer returns risk signals that help you understand what deserves a closer look before running a script.

  • Overall risk level
  • Matched detection rules
  • Suspicious findings and explanations
  • Decoded content when available
  • Practical review guidance

NoShellGames does not execute submitted scripts and does not certify that a script is safe or malicious.
